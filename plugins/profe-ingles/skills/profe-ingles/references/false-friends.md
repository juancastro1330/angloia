# Falsos amigos (español → inglés)

Úsalo al elegir el ⚠️ o el 🔑 cuando el mensaje del usuario contiene una palabra trampa. Elige **una** relevante para lo que el usuario escribió; no listes varias.

**Cómo leer las tablas:** cada fila parte de lo que el usuario quiere decir en español y muestra la palabra inglesa que *parece* correcta pero no lo es, qué significa realmente y cómo se dice lo que quería.

**Regla:** si una palabra no está aquí y no estás completamente seguro de que sea un falso amigo, no lo afirmes.

## Falsos amigos parciales

Estas palabras **sí** sirven en algunos sentidos y fallan en otros. Explica solo el sentido que falla.

| Palabra | Cuándo falla | Se dice |
|---|---|---|
| *realize* | "realizar una tarea" (hacer) | *carry out*, *do*, *complete*. *Realize* significa "darse cuenta" |
| *eventually* | "eventualmente" (posiblemente, a veces) | *possibly*, *occasionally*. *Eventually* significa "finalmente" |
| *support* | "no soporto el ruido" (aguantar) | *I can't stand the noise*, *put up with*. *Support* es apoyar o sostener |
| *pretend* | "pretendo terminar hoy" (tengo la intención) | *I intend to*, *I'm trying to*. *Pretend* es fingir |
| *ignore* | "ignoro la respuesta" (no la sé) | *I don't know the answer*. *Ignore* es no hacer caso a propósito |
| *discuss* | "discutimos" (peleamos) | *argue*, *fight*. *Discuss* es hablar de un tema con calma |
| *introduce* | "introducir una moneda" (meter) | *insert*, *put in*. Presentar a una persona → *introduce* (no *present*) |
| *present* | "presentar a alguien" | *introduce*. *Present* sirve para presentar un informe o un premio |

## Cognados que sí funcionan

Sirven para dar confianza al usuario. Patrones frecuentes y fiables:

- **-ción → -tion:** información → *information*, nación → *nation*.
- **-dad → -ty:** universidad → *university*, calidad → *quality*.
- **-oso → -ous:** famoso → *famous*, curioso → *curious*.
- **-mente → -ly:** finalmente → *finally*, rápidamente → *rapidly*.
- **-ante / -ente → -ant / -ent:** importante → *important*, inteligente → *intelligent*.

Hay excepciones; aplica el patrón solo cuando estés seguro de la palabra.
